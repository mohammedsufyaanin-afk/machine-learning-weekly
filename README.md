# 🤖 Machine Learning Weekly

Welcome to my Machine Learning journey! 🚀 

This repository serves as a personal log and portfolio where I document my progress, experiments, projects, and key concepts as I prepare for my Machine Learning major.

---

## 💡 About The Repo

After completing the **Elements of Data Processing** course at university, I fell in love with Data Science and Machine Learning. Instead of waiting for my university's ML coursework to start, I decided to jump ahead and build a strong foundation independently.

This repo is a living record of:
* **Weekly Learnings & Milestones:** Notes, code snippets, and key takeaways.
* **Hands-on Projects:** Mini-projects applying theory to real-world datasets.
* **Core Concepts:** Explorations into Neural Networks, Sentiment Analysis, Natural Language Processing (NLP), and Computer Vision.


## 🛠️ Tools & Technologies

* **Language:** Python 🐍
* **Libraries & Frameworks:** Pandas, NumPy, Scikit-Learn, PyTorch / TensorFlow, Matplotlib, Seaborn
* **Environment:** Jupyter Notebooks, VS Code
